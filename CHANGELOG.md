# Changelog

All notable OpenDelegate changes are recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and released versions
follow Semantic Versioning once the first public API is tagged.

## [Unreleased]

### Added

- Approved product, architecture, threat-model, and implementation specifications.
- Cross-platform TypeScript monorepo foundation.
- Deterministic simulated Task journey with canonical Task identity and a stable Forum binding in a
  replayable in-memory seam, retry-safe Work Orders and Artifact publication, policy and lease
  gates, selective local Knowledge retrieval, and fake Computer Use evidence.
- Domain, protocol, event-store, scheduling, Secret, transport, Agent-adapter, resource-lock, and
  orchestration public contracts with negative-path tests.
- Initial Admin Web Device overview and isolated Configuration Chat, with responsive desktop/mobile
  browser coverage, accessible modal behavior, and privacy-safe Knowledge health.

### Changed

- Unified Work Order and Worker Report validation in Protocol, and moved deterministic eligibility,
  preference fallback, and bounded tie exposure into Scheduler.
- Made the orchestration journal own Task-stream identity and Work Order/Artifact fingerprints, with
  fail-closed replay-tamper coverage.
- Reworked Admin Web around an injected cross-platform Device view model, truthful per-Device
  configuration sessions, fixed chat composition, keyboard focus containment, AA contrast, axe
  scans, and a verified 320 CSS px floor.
- Added executable workspace dependency and test-discovery guards, isolated package typechecks,
  immutable GitHub Action pins, retained browser-failure diagnostics, and structured public issue
  intake.
